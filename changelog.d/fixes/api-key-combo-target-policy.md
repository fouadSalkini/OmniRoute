- **fix(api):** honor `allowedCombos` during combo candidate pre-dispatch checks (#12886 follow-up). When an API key had both `allowedCombos` and `allowedModels` restricted, `comboTargetPassesKeyModelPolicy` verified inner targets only against `allowedModels`, causing all targets of an explicitly authorized combo to be skipped with 503/429 unless every inner model was also individually allowlisted in `allowedModels`. The pre-dispatch check now acknowledges `allowedCombos` for non-auto combos while preserving per-candidate model restrictions for `auto/*` routers.
