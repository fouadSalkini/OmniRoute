- **fix(conversations):** parallel agents on one API key no longer re-insert their whole history as a new conversation on most requests. Reconnect candidates were the 20 most recently seen conversations in an apiKeyId + model + tool-names bucket that every agent on the key shared, so with more than 20 active agents a session's own conversation fell out of the window and its next request copied hundreds of turn nodes again (about 1.3M rows, ~1 GB a day, on one deployment). When the client sends a session id (`x-claude-code-session-id`, Codex `session_id`, opencode `x-opencode-session`, or Claude's `metadata.user_id` session), the bucket is now that session; the old bucket is still searched so existing conversations keep continuing. ([#15637](https://github.com/diegosouzapw/OmniRoute/pull/15637))
